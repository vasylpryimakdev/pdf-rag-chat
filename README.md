# PDF Chat RAG Test Task

Test task implementation for a PDF-based AI chat app.

## Planned Stack

- Frontend: Next.js, React, TypeScript, TanStack Query
- Backend: NestJS, TypeScript, MongoDB/Mongoose
- File storage: AWS S3
- Workflow: AWS Step Functions and AWS Lambda
- AI: OpenAI
- Vector DB: Pinecone

## Project Structure

```text
apps/
  web/      # Next.js frontend
  api/      # NestJS backend
infra/      # AWS Lambda and Step Functions infrastructure
```
